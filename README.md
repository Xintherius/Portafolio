# Data Analytics & Business Intelligence Portfolio

A collection of data analytics and business intelligence projects focused on relational schema design, SQL data transformations, exploratory data analysis, and interactive dashboard development in Tableau.

---

## Projects Overview

### Global Video Game Sales & Market Trends Analysis
* **Stack:** Tableau, SQL (MySQL), Exploratory Data Analysis
* **Summary:** Analyzed historical multi-platform video game sales records to identify regional market divergence (North America, Europe, Japan), publisher market share concentration, and platform revenue lifecycles.
* **Documentation & Files:** [Browse Video Game Project](./Videogame%20Sales%20Analysis/)

### E-Commerce Customer Segmentation & Retail Analytics
* **Stack:** SQL (MySQL), Tableau, Relational Data Modeling
* **Summary:** Developed an end-to-end data auditing, cleaning, and schema optimization pipeline in MySQL on transactional retail data. Standardized datetime structures, calculated behavioral RFM metrics via SQL queries, and built Tableau dashboards to evaluate customer segment distributions and revenue trends.
* **Documentation & Files:** [Browse Retail Analytics Project](./Retail%20Customer%20Segmentation/)
