# Global Video Game Sales & Market Trends Analysis

An exploratory data analysis and business intelligence study examining historical global video game sales across gaming platforms, genres, publishers, and geographic regions.

---

## Project Overview

This project analyzes the historical commercial performance of over 16,000 video game titles to evaluate how regional consumer behavior, publisher strategies, and console lifecycles impact software revenue.

### Core Objectives
* Clean, audit, and model raw transaction records using SQL and structured CSV extracts.
* Evaluate regional revenue divergence across North America, Europe, Japan, and Other global markets.
* Track publisher market share concentration and platform lifecycle performance over multiple console generations.
* Design an interactive Tableau dashboard providing intuitive filtering and visual drill-downs for stakeholders.

---

## Project Structure

* `data/` - Contains both raw source files and processed datasets.
* `sql/` - Contains SQL scripts for data cleaning, transformation, and exploratory queries.
* `images/` - Contains visual exports, charts, and dashboard previews.
* `videogames_sales.twbx` - Packaged Tableau workbook containing interactive dashboards and embedded data extracts.

---

## Technical Stack & Methods

* Business Intelligence: Tableau Desktop, Tableau Public
* Database & Querying: SQL (MySQL: Aggregations, Window Functions, Grouping, Filtering)
* Data Processing: Missing value imputation, schema standardization, categorical grouping

---

## Key Analytical Insights

* Regional Market Divergence: Consumer preferences vary significantly by geography. The Japanese market demonstrated consistent demand for Role-Playing Games (RPGs), whereas North American and European markets showed dominant preferences for Action, Shooter, and Sports titles.
* Publisher Concentration: Nintendo, Electronic Arts, and Activision maintained sustained revenue concentration across multi-generational console releases.
* Platform Lifecycle Dynamics: Peak software sales volume aligned with the 3- to 5-year post-launch maturity window for major console platforms.
